# ぜんにゅー 編集方針 Ver.0.2
更新日：2026年11月11日

## 中核原則

**正確さは本文の中で担保し、注意書きを結末にしない。**

「ぜんにゅー」は、世の中の前向きな変化を、読みやすい記事として届ける。情報の正確さと気持ちのよい読後感を両立する。ただし、記事の余韻のために未確認の事実を作ったり、重要な限定条件を伏せたりしてはならない。

## 本文制作ルール

1. 見出しは簡潔で具体的に。本文は原則「です・ます調」。
2. 「何が起きたか → どのような前進・改善につながる動きか → 確認できる具体的な内容」の順序を基本とする。ただし不自然な定型パターンは避ける。
3. 毎回末尾に「ただし」「なお」「現時点では」等の留意点を固定的に加えない。最終文はできる限り、確認できた出来事やその意義で自然に締める。
4. 予定と実施済み、採択と実装、実証と実績、自己申告と測定結果などの区別は、事実を述べる時点で適切に明示する。例えば「利用者アンケートでは54.4%が短縮を実感した」と書く。
5. 重要な制約が結論を覆すなら省略せず、本文中の分かりやすい箇所に明記する。必ずしも文末から禁止するわけではない。訂正や危険に関する注意は読者の理解を優先する。
6. 不確かな結果を「期待できます」「進んでいます」などの文で事実上の成功に変換しない。根拠がなければ人間の再確認に回す。
7. 一般的なAI生成や資料の限界に関する共通注意事項は **運営方針** の「編集方針」「AI利用方針」に集約し、各記事の「もとのニュース」欄から参照できるようにする。
8. 記事の一次情報の出典リンク、AI編集の開示、訂正や重要な注記は維持する。
9. 「留意点の削除」は情報の削除ではない。留意点を文中へ移すのか、共通注意へ集約するのか、根拠不足として掲載を控えるのかを判断する。

## 投稿前のチェック

- 主語・行動・実施段階・具体的数字は確認した情報の範囲か
- 文体は「です・ます調」で読みやすいか
- 末尾が定型の注意書きになっていないか
- 予定・推計など重要な制限は伝わるか
- 善兆としての見方と事実を混ぜていないか
- 出典が読者に示され、必要なら編集方針へアクセスできるか
- 論点を無理に前向きに締めていないか

## 安全性と適用範囲

- 公開済み記事の本文・スコア・公開状態・評価結果は一括書換えしない。
- 今回更新するのは静的な運営方針ページと記事側の編集方針へのリンク、および今後の執筆指針。
- OpenAI有料API呼び出し、自動公開設定の有効化、モック判定・ファクトパックの変更は行わない。
- 25件のGPT比較原稿や回答済み/進行中のブラインド比較素材は、実験の再現性のため変更しない。
- 今後の新しいGPT編集稿に適用する。旧バージョンの原稿は比較対象としてそのまま保持する。

## Ver.0.2.1 追加品質基準（2026年11月11日）

Ver.0.2の原則と「です・ます調」の親しみやすい文体は維持する。次の4つを追加。

1. **事実の段階の明確化**：採択・研究開始・実証・導入・成果を取り違えない。将来予定は予定として扱う。
2. **補足説明の出典管理**：元の発表にない制度・技術・影響の説明を当然の事実として補わない。出典が確認できなければ保留。
3. **結末の自由度**：定型的な「ただし」「なお」や根拠のない「期待されます」を結末に足さない。2段落で自然に終わるならそこで終える。
4. **1記事1善兆**：何が良くなった・前進したのか、読後に一つ残るように編集する。

### 公開判定との分離

文章の4基準が通っても、原文根拠の十分性・権利・重複・正式善兆スコア・公開審査は別工程。未検証の記事を本文の流暢さだけで公開しない。
