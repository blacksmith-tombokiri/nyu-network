## 試験範囲

- 既存ファクトパックにある文章を機械的に整え、タイトル・本文・留意点・出典を含む短文案を25件生成。
- 対象は2026年10月以降、アクティブかつ本番利用適格なGreenソースのファクトパック。
- 未掲載記事の試作品12件、既存記事と比較するサンプル13件。既存記事は変更せず、比較用にタイトル・要約のスナップショットだけ保存。
- 以前に削除した2026年6〜9月の試験候補は使用しない。
- バッチID：`noapi_20261111_v01`。
- **API使用はゼロ**。試作はDB側SQLの一括テンプレート整形で生成。定期自動生成・常時稼働のエンジンを実装したわけではない。今回は比較実験として単発生成した。
- 自動生成に使用した資料自体は旧ファクトパックも含む。25件中、厳格なVer.0.4の公式HTML照合を通過していたのは1件のみ。残り24件は根拠の再確認が必要。

## 隔離したデータと管理画面

- 公開スキーマの専用テーブル `nyu_template_draft_trials` に保存し、`publication_eligibility=false` と `trial_status=test_only` のチェック制約で必ず公開不可。
- `nyu_articles` と `nyu_evaluations` を増やさず、編集デスクの通常の善兆スコアや公開RPCから完全に分離。
- RLS有効、一般公開のanonロールにはSELECT権限なし。authenticatedの非管理者はRLSで0件。管理者の疑似JWTで25件参照できることをDBで検証。
- GitHub: `nyu-admin/template-draft-trials.html`。編集デスクの `index.html` から遷移。ブラウザー実操作は未確認。
- 試験ページで、試験文・元ソースリンク・旧記事との並列表示・確認済み/要再検証・機械的な診断値・注意フラグを確認できる。
- 比較ページに「公開」ボタンを設けていない。

## 具体例と品質上の弱点

- 国土交通省・ひとり親控除の政令改正：試作は「35万円→38万円」などの事実を短く列挙しただけ。旧記事は「政府が閣議決定した」「直ちに家賃が下がった意味ではない」など読者が誤解しやすい点を自然文で説明しており、読みやすさ・独立した記事としての完成度では旧記事が優位。
- Horizon Magazine の風車翼摩耗対策：元ニュースの英語タイトルをそのまま使用し、日本語本文も短く不自然な要約である。見出し翻訳・文体統一・出典理解は未実装。
- 4Gamerの一般商品告知も未掲載サンプルに混入。既存のGreen利用許可は**善兆としての価値の高さを意味しない**。
- Ver.0.4の料理マスターズ受賞者記事は事実確認に成功。ただし授与式が実施済みとは書いておらずとも、短文案が記事として十分かは別判定。
- 原文再検証が必要な24件には、過去にRSSタイトルや要約だけから作成されたファクトパックが含まれる。公開してはならない。

## 判定

**試験用記事案の自動作成・保存機能は実証済み。未検証の内容を記事化して公開する機能は未着手。**
この試験は「APIなしで十分な記事品質になるか」を検証したものであり、現段階では **NO-GO**。

今後の改善順位：
1. 公式HTMLの根拠と対象イベントの真正性を検証するプロセスを充実させる。古いRSS由来の情報をそのまま公開対象にしない。
2. タイトルを書き換えるときは原文の事実だけを使う。行為者と対象の混同、予定と成果の混同、未確認数値を厳禁。
3. 記事本文を「誰が／何をした／読者に何が変わる／未確認点」と分ける。最後の「読者に何が変わる」は根拠がない場合は「不明」と表示。
4. 善兆価値は形式点で判定せず、独立した編集基準で判断する。
5. 比較用の記事に対して、事実正確性、見出し独自性、読みやすさ、文脈、掲載価値を人手で採点し再検証する。
6. 品質が通過して初めて定期生成ジョブや本番の下書き管理画面との連携を検討する。
